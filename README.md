# Quote Generator 🚀

A modern, animated, and responsive **Quote Generator** web app with **dark mode**, **RGB moving background**, and **smooth animations**. Perfect for daily inspiration and learning modern front-end techniques.

---

## 🌟 Features

- 💡 **Random quotes** with author  
- 🌙 **Dark & Light mode toggle**  
- 🌈 **Animated RGB background**  
- 🖱️ **Smooth button animations** with gradient & ripple effects  
- 🐦 **Tweet quotes** directly to Twitter  
- 🖥️ **Responsive design** for desktop & mobile  
- 🏆 Eye-friendly colors & subtle UI animations

---

## 💻 Installation

1. **Clone the repository**

```bash
git clone https://github.com/AdityaSadewale/Quote-Generator.git
Go to the project folder

cd Quote-Generator
Open index.html in your browser

No dependencies needed. Pure HTML, CSS, and JavaScript.

🚀 Usage
Click New Quote to generate a random quote

Click Tweet to share on Twitter

Click Copy to copy the quote to clipboard

Click the 🌙 / ☀ button to toggle Dark/Light mode
